# Simulation Results

The processor was simulated to verify the execution of the iterative Fibonacci program.

The waveform can be used to observe:

- Program counter progression
- Pipeline register operation
- Register updates
- Fibonacci computation
- Branch and loop execution
- Output register R7

## Add your simulation screenshot

Rename your simulation screenshot to:

`waveform.png`

and place it in this folder.

After uploading the image, this README can be updated to display it:

```markdown
![Simulation Waveform](waveform.png)
```
